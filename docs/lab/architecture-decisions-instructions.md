## 1. Technical & Architectural Decisions

Arquivo recomendado:

```txt
/docs/lab/architecture-decisions.md
```

### Objetivo

Registrar decisões técnicas e arquiteturais tomadas durante a implementação dos Labs 01, 02 e 03.

### Quando registrar

O Codex deve registrar uma decisão quando:

```txt
- escolher uma estrutura de dados
- definir comportamento de parsing/mapping/projeção
- alterar o modelo de FCID
- alterar o modelo de FCAS
- criar uma convenção técnica
- encontrar uma ambiguidade arquitetural
- aplicar uma simplificação temporária
- identificar débito técnico consciente
```

### Template

```md
# ADR-000 — Título da decisão

## Data

YYYY-MM-DD

## Lab relacionado

Lab 01 — Artifact Mapping  
Lab 02 — Projection Engine  
Lab 03 — FCAS Resolution

## Contexto

Descreva o problema ou incerteza.

## Decisão

Descreva a decisão tomada.

## Alternativas consideradas

- Alternativa A
- Alternativa B

## Motivo

Explique por que essa decisão foi escolhida.

## Impacto

Explique o que essa decisão afeta.

## Status

Proposta | Aceita | Revisar depois | Substituída

## Observações

Notas adicionais.
```
